# Portfólio | Isabella Andrade

Portfólio profissional responsivo desenvolvido para apresentar minha trajetória, competências, formação, cursos e projetos realizados para clientes.

## Sobre o projeto

O site reúne informações sobre minha atuação como estagiária em desenvolvimento web, com experiência em criação e manutenção de sites, implantação de sistemas, suporte a usuários, treinamento de clientes e configuração de chatbots.

Também apresenta projetos que já estão em funcionamento, incluindo sites institucionais e e-commerces.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Devicon](https://devicon.dev/) para os ícones de tecnologias
- [Simple Icons](https://simpleicons.org/) para o ícone do Elementor

## Funcionalidades

- Navegação fluida entre as seções da página
- Layout responsivo para computador e celular
- Seções de apresentação, experiência, formação, cursos e competências
- Cards de projetos com links para os sites publicados
- Formulário que inicia uma conversa pelo WhatsApp
- Favicon personalizado

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em seu navegador.

Se usar o VS Code, a extensão Live Server também pode ser usada para visualizar o projeto localmente.

## Estrutura de arquivos

```text
portifolio/
├── img/             # Fotos, imagens dos projetos e favicon
├── index.html       # Estrutura e conteúdo da página
├── styles.css       # Estilos e responsividade
└── README.md        # Documentação do projeto
```
